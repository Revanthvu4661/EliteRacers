# Assets

Drop files here. Reference them from `cars.js` (models, engine sounds) or `track.js` (textures).

- `models/`   .glb / .gltf car models (CC0 low-poly). Keep under ~2 MB each. Y-up, facing -Z, wheels touching y=0.
- `sounds/`   .mp3 / .ogg loops for engines, one-shots for collisions.
- `textures/` road, grass, skybox images.

No code changes needed to add a car: append an entry to `CARS` in `cars.js`.
